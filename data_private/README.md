# Private/local data directory

Do **not** commit participant-level NHANES or KNHANES data to the public repository.

For local reruns, place authorized analysis-ready files here (or configure an alternate path):
- `knhanes_2008_2011_paper3_ready.csv.gz`
- `knhanes_2024_paper3_ready.csv.gz`

These files are intentionally excluded from the public release.
