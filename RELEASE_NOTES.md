# Release notes — v1.0.0

Initial public release supporting the definition-dependent low-muscle prediction manuscript.

## Included
- Frozen U.S. five-predictor and four-predictor model objects.
- Development-defined 80% and 90% sensitivity thresholds.
- Aggregate U.S. locked temporal-validation results.
- Sanitized KNHANES external-validation scripts.
- Aggregate KNHANES 2008–2011 and 2024 results.
- Bootstrap replicate summaries.
- External-validation figures.
- Label/direction and final QA records.
- Software environment and analysis manifest.

## Not included
- Participant-level NHANES records.
- Participant-level KNHANES records.
- Analysis-ready KNHANES cohort files.
- Raw KNHANES source files.

The KNHANES 2024 validation is restricted to ages 40–59 years.
